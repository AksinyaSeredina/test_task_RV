# Структура
- Анализ.pdf

Материалы анализа
- oval_parser.py 

Скрипт, преобразующий oval в упрощенный формат.

---

## Требования

* **Python 3.8+**
* Сторонние библиотеки не требуются (используются только модули стандартной библиотеки: `xml.etree.ElementTree`, `json`, `re`, `sys`, `argparse`).

---

## Установка и подготовка

1. Сохраните исходный код парсера в файл `oval_parser.py`.
2. Поместите целевой OVAL XML-файл (например, `rhel-8.oval.xml`) в рабочую директорию со скриптом (или укажите абсолютный путь при запуске).

---

## Использование

### Синтаксис запуска

```bash
python oval_parser.py <путь_к_файлу_oval.xml> [-l LIMIT] [--split]

### Примеры запуска
1. Базовый запуск (вывод в консоль)
Извлекает первые 5 уязвимостей и выводит их в stdout в виде форматированного JSON-массива:

python oval_parser.py rhel-8.oval.xml

2. Извлечение заданного количества записей
Извлечь ровно 1 уязвимость (выводится как единичный JSON-объект):

python oval_parser.py rhel-8.oval.xml -l 1

Извлечь первые 10 уязвимостей:

python oval_parser.py rhel-8.oval.xml -l 10

4. Пакетное сохранение в отдельные файлы
При указании флага --split скрипт создаст в текущей директории отдельные файлы для каждого бюллетеня ( например RHBA-2019-1992.json, RHBA-2019-2715.json):


python oval_parser.py rhel-8.oval.xml -l 5 --split
